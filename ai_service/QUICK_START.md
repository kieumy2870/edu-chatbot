## 📌 Fastest Way to Run

### **Step 1: Add Your API Key**
Edit `d:\pythonProject\edu-chatbot\ai_service\.env`:
```
GEMINI_API_KEY=paste_your_key_here
```

### **Step 2: Run the Server**
```powershell
cd d:\pythonProject\edu-chatbot\ai_service
.\run_server.bat
```

That's it! Server runs at `http://localhost:8000`
